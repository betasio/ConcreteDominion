# Concrete Dominion approved city atlas

This runtime atlas contains the first approved generated art pack for the core city.

## Format

- decoded image: WebP
- atlas dimensions: 320×160
- cell dimensions: 80×80
- grid: 4 columns × 2 rows
- runtime loader: `scripts/content/PresentationCatalog.gd`

## Visual direction

- premium 2.5D isometric crime-strategy architecture
- charcoal concrete and matte black structures
- restrained warm-gold highlights
- selective red emergency/security accents
- cool cyan used for intelligence/data technology
- strong silhouettes that remain readable at mobile scale

High-resolution generated masters are retained outside the runtime bundle. This atlas is the optimized in-game derivative.
